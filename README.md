# Oilkara — ห้องคาราโอเกะ YouTube

ค้นหาเพลงคาราโอเกะจาก YouTube ต่อคิวหลายเพลง แล้วร้องต่อเนื่องอัตโนมัติ
เพื่อนสแกน QR บนจอเพื่อขอเพลงจากมือถือเข้าคิวเดียวกันได้

## เริ่มใช้งาน

1. ติดตั้ง Python 3.8 ขึ้นไป (Windows: ติ๊ก **Add python.exe to PATH** ตอนติดตั้ง)
2. ดับเบิลคลิก `start-windows.bat` (Mac: `start-mac.command`) หรือรัน `python server.py`
3. เบราว์เซอร์จะเปิด `http://localhost:8000/` ให้อัตโนมัติ กด **เริ่มเลย** หนึ่งครั้ง
4. ให้เพื่อนสแกน QR บนจอ (มือถือต้องต่อ Wi-Fi วงเดียวกับคอม)

> Windows อาจถามสิทธิ์ Firewall ตอนรันครั้งแรก ให้กด Allow สำหรับ Private network
> ไม่เช่นนั้นมือถือจะเปิดหน้าขอเพลงไม่ได้

## ฉายขึ้นทีวี (โหมดทีวี)

1. ต่อคอมเข้าทีวีด้วย HDMI แล้วตั้งจอเป็นแบบ **ขยาย (Extend)** (Windows: กด `Win + P` → Extend)
2. ที่หน้าจอหลัก กด **📺 เปิดจอทีวี** หน้าต่างใหม่จะเปิดขึ้น
3. ลากหน้าต่างนั้นไปไว้บนทีวี แล้วกด **เริ่มฉายบนจอนี้** วิดีโอจะขยายเต็มจอทีวี
4. หน้าจอหลักบนโน้ตบุ๊กจะกลายเป็นรีโมตเอง: เล่น/หยุด เริ่มใหม่ ข้ามเพลง และจัดคิว ทุกปุ่มสั่งจอทีวี

จอทีวีแสดงชื่อเพลงและคนร้องตอนเริ่มเพลง, QR ขอเพลงที่มุมขวาบน, แถบความคืบหน้าด้านล่าง
และการ์ดนับถอยหลังพร้อมเพลงถัดไปอีกสองเพลง ถ้าปิดหน้าต่างทีวี หน้าจอหลักจะกลับมาเล่นเองภายในไม่กี่วินาที

เปิดตรงๆ ได้ที่ `http://localhost:8000/tv` (หรือ `http://IP-ของคอม:8000/tv` จากเครื่องอื่นในวง Wi-Fi เดียวกัน)
ปุ่มลัดบนจอทีวี: Space เล่น/หยุด · N ข้าม · F เต็มจอ

## ความสามารถ

- ค้นหาเพลง เติมคำว่า “คาราโอเกะ” ให้อัตโนมัติ
- วางลิงก์ YouTube ทีละเพลง หลายลิงก์ หรือลิงก์เพลย์ลิสต์
- คิวเรียงลำดับได้ (ลาก, ↑↓), สุ่ม, ลบ, กดร้องเพลงไหนก่อนก็ได้, ใส่ชื่อผู้ร้อง
- จบเพลงแล้วนับถอยหลัง 5 วินาที โชว์เพลงถัดไปและชื่อคนร้อง แล้วเล่นต่อเอง
- วิดีโอที่เจ้าของไม่อนุญาตให้ฝัง จะถูกข้ามอัตโนมัติ
- หน้ามือถือ (`/request`): ใส่ชื่อ ค้นหา/วางลิงก์ ขอเพลง ดูลำดับคิว ยกเลิกเพลงของตัวเอง
- บันทึกเพลย์ลิสต์ไว้ร้องรอบหน้า ส่งออก/นำเข้าเป็น .json
- ปุ่มลัด: Space เล่น/หยุด · N ข้าม · P ย้อน · R เริ่มใหม่ · F เต็มจอ

## ค้นหาในแอป (ไม่บังคับ)

ถ้าไม่มี API key ปุ่มค้นหาจะเปิด YouTube ให้เลือกเพลงแล้วคัดลอกลิงก์กลับมาวาง
ถ้าอยากเห็นผลค้นหาในแอปเลย (ทั้งจอหลักและมือถือ):

1. เข้า Google Cloud Console → สร้างโปรเจกต์ → เปิดใช้ **YouTube Data API v3**
2. Credentials → Create credentials → API key
3. ที่จอหลัก แท็บ **ค้นหา** → ตั้งค่า YouTube API key → บันทึก

คีย์เก็บไว้ใน `karaoke_data.json` บนเครื่องที่รันเซิร์ฟเวอร์ มือถือไม่เห็นคีย์

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `server.py` | เซิร์ฟเวอร์คิวกลาง (Python มาตรฐาน ไม่ต้องติดตั้งเพิ่ม) |
| `karaoke.html` | จอหลัก เล่นวิดีโอ จัดคิว แสดง QR (เป็นรีโมตเมื่อเปิดจอทีวี) |
| `tv.html` | จอทีวี วิดีโอเต็มจอ QR มุมจอ ชื่อคนร้อง นับถอยหลัง |
| `request.html` | หน้าขอเพลงบนมือถือ |
| `karaoke_data.json` | คิว ประวัติ เพลย์ลิสต์ (สร้างเองตอนรัน) |

เปลี่ยนพอร์ต: `python server.py 9000`
